## 3A. Visual Direction

### 1. Brand direction

**Positioning:** Premium English Educational Materials · Teacher-first · Clean · Trustworthy · Technically sophisticated

**핵심 아이디어: "인쇄된 시험지 자체가 브랜드의 얼굴이다."**

- 저가형 문제 판매 사이트는 할인 배너, 원색 버튼, 썸네일 이미지 위 큰 글씨로 판다. 지영랩은 **자료 자체를 보여주고** 품질로 판다.
  모든 상품 카드, 히어로, 샘플 뷰어는 HTML로 그린 **실제 시험지 페이지**(문항, 선지, 해설, 어휘표)를 보여준다.
- 브랜드 고유 요소는 **OMR 답안지의 붉은 인쇄색**이다. 시험지와 답안지는 이 사업의 세계에서 가장 익숙한 물건이다.
  이 붉은색은 **결정이 일어나는 곳에만** 쓴다: 구매 버튼, 할인율, 히어로 시트에서 마킹되는 정답, 현재 버전 표시.
- "기술적으로 정교함"은 장식이 아니라 **정보로** 표현한다: 상품 코드(`JY-M2609-H2-TA`), 버전 스탬프(`v1.2 · 2026.09.19`),
  수정 이력 타임라인, 문항 번호별 커버리지 표. 이것들은 실제 운영 데이터 모델(Phase 2 §3)에서 그대로 온다.
- 톤: 차분하고 단정하다. 과장 없이 "무엇이 들어 있고, 어떻게 만들었고, 어떻게 받는지"를 말한다. **가짜 후기, 가짜 판매량, 가짜 평점은 쓰지 않는다**
  (신뢰 신호는 과정과 정책으로만 만든다).

**Wordmark (임시, D10):** 둥근 사각형 안에 OMR 버블 두 개(빈 것 하나, 붉게 칠한 것 하나) + "지영랩" + `JIYOUNGLAB`.
"선택하고 표시한다"는 의미이고, 정식 로고가 나오면 `components/Cards.tsx`의 `Logo` 하나만 바꾸면 된다.

### 2. Typography

| 역할 | 서체 | 용도 | 이유 |
|---|---|---|---|
| Display | **Hahmlet** (600) | 페이지 제목, 섹션 제목, 가격, 시트 제목 | 한글 세리프 계열의 현대적 해석. 교재·출판물의 권위감을 주되 고전 명조보다 날렵하다 |
| Body / UI | **IBM Plex Sans KR** (400–700) | 본문, 버튼, 폼, 내비게이션 | 기술적이고 단정한 산세리프. 기본값 서체(Pretendard, Noto Sans)와 다른 인상 |
| Utility | **IBM Plex Mono** (400–500) | 상품 코드, 버전, 날짜, eyebrow 라벨, 문항 번호 | "정확한 데이터"의 목소리. Plex 패밀리라 본문과 조화 |
| Sheet | Hahmlet (400) | 시험지 안의 영어 지문 | 인쇄된 시험지의 세리프 지문 느낌 |

- **Type scale (px):** 11 · 12 · 13 · 14 · 15(본문 기본) · 16.5(장문 본문) · 20 · 22 · 26 · 32 · 40 · 48 · 56
- 제목은 `letter-spacing: -0.02 ~ -0.035em`, `text-wrap: balance`. 한국어는 `word-break: keep-all`로 단어 중간 줄바꿈을 막는다.
- 숫자 열(가격, 쪽수, 문항 수)은 `tabular-nums`.
- 블로그 본문은 최대 68자 폭, 행간 1.85.
- 모든 서체는 Google Fonts에서 불러오며 시스템 fallback stack을 지정했다. 출시 시에는 self-host로 바꾸는 것을 권장한다(Phase 2 성능).

### 3. Spacing / Grid

- **컨테이너:** 최대 1200px, 좌우 여백 20px(모바일) / 32px(태블릿 이상)
- **기본 단위:** 4px. 자주 쓰는 간격은 8 · 12 · 16 · 20 · 24 · 32 · 40 · 56 · 80 · 96
- **섹션 간격:** 홈과 허브는 섹션 사이 96px(`pt-24`), 페이지 내부 블록은 48px
- **카드 그리드:** 1열(모바일) → 2열(≥640) → 3–4열(≥1024). 카드 사이 20px
- **상세 페이지:** 갤러리 1.15 : 구매 패널 1, 구매 패널은 데스크톱에서 sticky
- **모서리:** 버튼 10px, 카드 14px, 큰 패널 18px. 단, 시험지 시트는 **모서리 0**(인쇄물)

### 5. Navigation

- **GNB (데스크톱):** 로고 · 시험별 자료 · 전체 자료 · 무료자료 · 블로그 · 지영랩 소개 | 검색창 · 로그인 · 장바구니(개수 배지)
  - 현재 위치는 OMR 붉은 밑줄 2px로 표시
  - Header는 sticky + 반투명 블러 배경
- **모바일:** 로고 · 장바구니 · 메뉴 버튼 → 펼침 메뉴(검색 + 전체 메뉴 + 고객센터)
- **두 탐색 축** (Phase 1 §3.2): "시험별"(회차 허브)과 "전체 자료"(필터). 자료 유형은 필터와 허브 탭으로 처리
- 모든 하위 페이지에 breadcrumb. 상품 상세는 `홈 > 전체 자료 > 2026 고2 9월 모의고사 > 18–30번`처럼 **시험 허브를 경유**하게 해 SEO 내부 링크 구조와 맞춘다

### 7. Collection / Exam cards

- 카드 우측에 **큰 월 숫자**("09")를 Hahmlet으로 크게 표시한다. 시험 회차를 숫자로 알아보는 교사의 습관을 반영했다.
  hover 시 숫자가 OMR 붉은색으로 바뀐다.
- 상단에 `모의고사 · 전국연합학력평가` 같은 출처를 mono 라벨로 붙인다.
- 이번 시즌 대표 회차 하나는 **반전 카드(잉크 배경)** 로 강조한다.
- 허브 페이지 상단은 제목 + 소개 + **사실 4칸(대상 · 시행 · 범위 · 자료 수)** 으로 구성한다.

### 10. Sample / Preview presentation

- **샘플은 숨기지 않는다.** 상품 상세 갤러리에서 앞 2쪽(무료자료는 3쪽)을 바로 보여주고, 그 뒤 페이지는 **흐리게 + 자물쇠**로 "구매 후 전체 N쪽"을 보여준다.
  무엇이 잠겨 있는지 보이는 것이 신뢰를 만든다.
- **샘플 뷰어(모달):** 큰 시트 + 6쪽 썸네일 + 샘플 구성 설명 + "샘플 PDF 받기" + "장바구니 담기"
- 패키지는 포함 자료 시트를 격자로 보여주고, 각 시트를 누르면 해당 자료의 샘플이 열린다.
- **저작권(D6):** 시트에 쓰인 영어 지문은 모두 **프로토타입용으로 새로 쓴 문장**이다. 공개 페이지(허브, 상세)는 원문 지문을 싣지 않고,
  문항 번호, 유형, 커버리지만 보여준다. 실제 출시 시 미리보기 이미지는 Phase 2의 `preview_reviewed` 승인 절차를 따른다.

### 11. Pricing presentation

- 단품: 가격 하나만 크게 보여준다. 가짜 정가나 상시 할인 표시는 쓰지 않는다.
- 패키지: `27% · 29,000원 · ~~39,500원~~`. **할인율과 정가 합계는 포함 자료의 현재 가격에서 계산**한다(D12: 하드코딩 없음, `lib/format.ts`의 `packageBreakdown`).
- 상세 페이지 라이선스 선택: **개인용 (가격) / 학원용 (견적 문의)**. 학원용을 고르면 구매 버튼이 견적 문의로 바뀐다(D3).
- 단품 상세에는 "이 자료가 포함된 패키지 · 27% 절약" 박스를, 장바구니에는 **같은 패키지 자료를 2개 이상 담으면 "패키지로 바꾸기" 제안**을 띄운다.

### 12. Trust / Quality signals

가짜 수치 대신 **검증 가능한 과정과 정책**으로 신뢰를 만든다.

1. **제작 4단계:** 지문 해부 → 각도 선택 → 오답 설계 → 교차 검수 (홈, 블로그)
2. **수정 이력 공개:** 모든 상품에 버전과 변경 내용을 기록한 타임라인. 히어로에도 "v1.2 반영됨" 카드
3. **샘플 공개:** 로그인 없이 앞 페이지 공개
4. **HWP 편집본:** 형식 칩과 파일 구성 표로 명시
5. **문항별 커버리지 표:** 허브에서 어떤 자료가 몇 번을 다루는지 공개
6. **명확한 환불·라이선스:** 상세 페이지와 구매 신청 화면에서 같은 문장으로 안내
7. **사업자 정보 footer** (전자상거래법 표시 의무 자리 확보)

### 13. Free-resource presentation

- teal 색 체계 하나로 "무료"를 일관되게 표시한다(배지, 버튼, 섹션 배경).
- 메시지는 "공짜"가 아니라 **"유료 자료와 같은 원고입니다. 써 보고 판단하세요."**
- 무료자료 페이지 구성: 히어로(무료자료 받기 3가지 방식) → **이번 주 무료자료** 강조 → 전체 목록 → **유료 자료 샘플** 띠.
- 받기 흐름: 이메일 입력 → 6자리 코드 → "내 자료실에 추가했습니다" → **관련 유료 자료로 연결**(Phase 1 J2 전환 경로).
- 블로그 글 안에 무료자료 카드를 넣어 콘텐츠 → 무료 → 유료로 이어지게 한다.

### 14. Responsive / Mobile behavior

| 영역 | 모바일 (<1024px) |
|---|---|
| Header | 로고 + 장바구니 + 메뉴. 검색은 펼침 메뉴 안으로 |
| 카탈로그 필터 | 사이드바 → "필터 N" 버튼 → 바텀 시트 모달 + "자료 N개 보기" |
| 상품 상세 | 갤러리 → 구매 패널 순서로 쌓임 + **하단 고정 구매 바**(가격 + 구매 신청) |
| 허브 커버리지 표 | 가로 스크롤, 번호 열 고정 |
| 장바구니 | 화면 전체 폭 드로어 |

**접근성 기본:** 키보드 focus 표시, 본문 건너뛰기, `aria-current`/`aria-expanded`/`aria-selected`, 폼 label 연결, `prefers-reduced-motion` 대응,
라이트/다크 모두 토큰 기반 대비 유지.

### Demo commerce 범위

- **실제처럼 동작:** 탐색 → 상세 → 샘플 → 라이선스 선택 → 장바구니(패키지 전환 제안 포함) → 구매 신청 폼
- **DEMO 상태로 전환:** 구매 신청 제출, 무료자료 받기(코드 입력), 학원 견적 문의, 고객 문의, 샘플 PDF 받기.
  각 지점에서 "데모: 실제로 ○○되지 않았습니다"를 명확히 표시한다.
- **하지 않는 것:** PG 호출, 주문 생성, 이메일 발송, 개인정보 저장, 파일 다운로드. 장바구니만 브라우저 localStorage에 저장한다(실패해도 동작).
- 화면 왼쪽 아래 `PROTOTYPE` 칩: 누르면 데모 사이트임을 설명한다(평소에는 화면을 방해하지 않음).

### 프로토타입이 하지 않는 것 / OWNER 확인 사항

- 법적 고지(약관·개인정보처리방침·환불정책·라이선스)는 자리만 있다. 화면의 환불 문구("다운로드 전 7일 이내 전액 환불")는 **데모 문안**이며 최종 정책은 OWNER가 정한다.
- footer 사업자 정보는 `○○○` 자리표시다.
- 가격, 버전, 날짜, 상품 구성은 모두 예시다.
- 교과서명(동아·NE능률)은 분류 체계를 보여주기 위한 메타데이터 예시이며, 실제 판매 여부는 저작권 workstream 결론을 따른다.
